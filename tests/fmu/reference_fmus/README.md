# Reference-FMUs v0.0.42

Test FMUs from the Modelica Association's [Reference-FMUs](https://github.com/modelica/Reference-FMUs),
release [v0.0.42](https://github.com/modelica/Reference-FMUs/releases/tag/v0.0.42), taken unchanged
from the release asset
[`Reference-FMUs.zip`](https://github.com/modelica/Reference-FMUs/releases/download/v0.0.42/Reference-FMUs.zip)
(sha256 `b6b4a195b9c0f6bdd3459cd949cbb35fc21ee2049d6dab4cb7a3ba7da63b1e97`).
Only BouncingBall, Dahlquist, Stair and VanDerPol are kept, each as FMI 2.0 and FMI 3.0.
